# Task 2 – Phishing Awareness Training

## Project Overview

This project was developed as part of the CodeAlpha Cybersecurity Internship to educate users about phishing attacks and social engineering techniques.

## Objectives

- Explain phishing attacks
- Identify phishing emails
- Recognize fake websites
- Understand social engineering tactics
- Share best practices to reduce phishing risks
- Reinforce learning through quizzes and a case study

## Deliverables

- Phishing Awareness Report (PDF)
- PowerPoint Presentation
- Supporting Screenshots

## Skills Demonstrated

- Security Awareness
- Email Security
- Social Engineering
- User Education
- Incident Prevention
